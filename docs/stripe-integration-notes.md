# Stripe — decisões de integração

A integração Stripe do projeto fornece as variáveis STRIPE_SECRET_KEY, VITE_STRIPE_PUBLISHABLE_KEY e STRIPE_WEBHOOK_SECRET automaticamente. O checkout deve ser criado no servidor com a sessão do usuário, usando `client_reference_id` e metadados de usuário/curso. O webhook deve ficar em `/api/stripe/webhook`, verificar a assinatura antes de processar eventos e responder `{ verified: true }` para eventos de teste cujo ID começa com `evt_test_`. O banco deve armazenar apenas referências essenciais para fulfillment e auditoria: identificadores de customer, sessão de checkout, payment intent e os IDs de produto/preço quando necessários; valores, status e recibos devem ser consultados no Stripe sempre que não houver justificativa de negócio para um cache local. O usuário precisa reivindicar o sandbox Stripe no prazo informado pelo painel e usar o cartão de teste 4242 4242 4242 4242 durante a validação.
